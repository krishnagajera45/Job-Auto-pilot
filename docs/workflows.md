# Agentic Workflows

## Tailor Workflow
1. Job parsing and requirement extraction.
2. RAG retrieval from user memory sources.
3. Resume tailoring with templates and tone.
4. Cover letter drafting.
5. Validation (ATS readiness, keyword coverage).
6. User review and approval.

## Application Workflow
1. Queue application request.
2. Verify approvals and consents.
3. Execute ATS connector or Playwright automation.
4. Log submission artifacts and status.
5. Notify user and update analytics.
