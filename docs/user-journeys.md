# User Journeys

## 1. Onboarding & Profile Setup
1. Sign up (email/OAuth).
2. Complete profile: skills, target roles, locations, salary, work authorization.
3. Import resume and portfolio links.
4. Set notification preferences.

## 2. Job Intake (Link/ID)
1. Paste job link or ID.
2. System parses the posting and extracts requirements.
3. User selects the target resume and optional cover letter template.

## 3. Tailor Documents
1. Agent retrieves relevant experience from memory store.
2. Resume and cover letter are tailored and scored.
3. User reviews and approves.

## 4. Apply & Track
1. Approval triggers ATS automation.
2. Application is submitted and logged.
3. Status updates and reminders flow to the dashboard.

## 5. Ongoing Optimization
1. Analytics highlight best-performing resumes.
2. Users refine preferences and templates.
3. System learns from outcomes for next applications.
